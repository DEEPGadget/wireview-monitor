wvd 1.0 v1.0.0 · 7700c09

2026-10-07 · 범위: 첫 릴리스(253f4b7, 7700c09)와 서버 cpu에 배포한 내용

단일 프로세스 데몬으로 출발한 기준 버전이다. 이 문서는 배포 구성, 50 Hz 운용 시 저장 용량 추정, 그리고 seriesA에서 실제로 써 보며 드러난 문제를 정리한다. 이 문제들이 1.1과 1.2의 작업 범위가 됐다.

구조배포저장 용량운영 중 문제부하 시험

구조

프로세스 하나가 수집 스레드, SQLite, HTTP 서버를 모두 담는다.

/dev/ttyACM0 ─ wvd (Python 프로세스 1개, GIL 1개)
                 ├─ wvd-sampler 스레드: 읽기 → store.add → 0.5초마다 flush → 60초마다 prune → publish
                 ├─ Store: RLock 1개 + SQLite 연결 1개 + 링 버퍼(900초)
                 └─ uvicorn: REST · WS/SSE · /metrics · 대시보드 (스레드풀에서 조회·통계·CSV 생성)

수집 스레드와 API 조회가 같은 잠금과 같은 GIL을 나눠 쓴다. 운영 중 드러난 문제는 대부분 이 구조에서 나왔다.

저장 용량 추정 (50 Hz, 보관 72시간)

샘플 하나가 한 행이다. 행에는 seq, 시각, 기기 UID(24 B), 원본 프레임(100 B)이 들어간다. 1분 동안 실측한 결과, 인덱스와 페이지 여유를 포함해 샘플당 약 165 B였다.

기간50 Hz10 Hz
1시간30 MB6 MB
1일0.71 GB0.14 GB
72시간 (보관 기간, 최종 크기)≈ 2.1 GB≈ 0.43 GB
  • 파일이 줄지 않는다. VACUUM을 하지 않으므로 지운 공간은 새 샘플이 다시 쓴다. 3일째쯤 최대 크기에 이른 뒤 그 크기를 유지한다.
  • 세션 구간의 샘플은 보관 기간과 무관하게 계속 남는다. 50 Hz에서 세션 1시간마다 30 MB씩 늘어난다.
  • 리뷰에서도 3시간에 93 MB가 쌓였다고 보고했다. 72시간이면 약 2.2 GB로, 위 추정과 같다.

seriesA 사용 중 드러난 문제

출처: reviews/wireview-monitor-issues.html. seriesA에서 wvd는 단순 기록기가 아니라 자동 중단(guard)의 유일한 데이터 소스였다. 그래서 수집이 멈추면 guard가 실험을 잘못 중단시키거나, 커넥터 상태를 보지 못하는 구간이 생긴다.

ID문제원인 (코드에서 확인)
C1USB 재연결 때 수집 스레드가 죽는다. HTTP는 마지막 값을 최신 값처럼 계속 응답한다.termios.error는 OSError의 하위 클래스가 아니다(issubclass 결과 False). 그래서 except (OSError, DeviceError)를 빠져나간다.
C2DB 조회 중 수집이 1.5~4.5초 멈춰 guard가 2회 잘못 중단시켰다.Store.range()와 after_seq()가 잠금을 잡은 채 flush와 fetchall을 한다. 수집 쪽의 next_seq()와 add()도 같은 잠금을 기다린다.
C3세션 종료와 대시보드 세션 목록이 C2를 일으킨다.세션 이벤트가 올 때마다 대시보드가 세션 15개의 전체 구간 통계를 다시 요청한다.
C4멈춘 구간의 측정값은 영구히 사라진다.기기에 버퍼가 없고, 수집 루프는 밀리면 따라잡지 않는다. 또 seq는 읽기에 성공할 때만 늘어서 seq만 봐서는 공백이 보이지 않는다.
E1GIL 경합수집과 API가 한 프로세스 안에 있다.
E2수집 스레드가 DB 기록과 prune까지 직접 한다.디스크 지연이 그대로 수집 정지로 이어진다.
E3내보내기가 50만 샘플(2.8시간)에서 아무 표시 없이 잘린다.LIMIT 500000. CSV 전체를 메모리에서 만든다.
E4스트림 큐가 40초분이라 느린 구독자는 오래된 데이터를 받는다.큐 2000개. 넘칠 때 오래된 것 하나만 버린다.
E5health가 스레드 사망을 드러내지 않는다.스레드가 죽어도 connected: true로 나온다.
E6인증 없이 열려 있다.무거운 요청 하나로 C2를 일으킬 수 있다.
E7DB 크기, 세션 구간 무기한 보관위 저장 용량 추정 참고
